Stroke glyphs from the app (plus, remove, close, grip) — use inside buttons; they inherit `currentColor`.

```jsx
<Icon name="plus" size={18} />
<Icon name="grip" size={16} />
```

- `plus` / `remove` stroke 2.25, `close` stroke 2, `grip` is six 1.5r dots.
- No icon library: these four are the whole set. Emoji flags carry the rest of the imagery.
